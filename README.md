# Gym Log

Gym attendance and exercise tracker. Vite + React + TypeScript + Tailwind v4 + Dexie (IndexedDB) + vite-plugin-pwa.

## Run locally
    npm install
    npm run dev

## Deploy on Vercel
Push to GitHub, then Import Project in Vercel. Framework preset: Vite (auto-detected). No env vars or settings needed.
`vercel.json` rewrites all routes to index.html so deep links work.

## Install on phone
Open the deployed URL. Android Chrome: menu > Install app. iPhone Safari: Share > Add to Home Screen.

## Data
Stored on-device in IndexedDB. Holidays tab > Backup exports/imports JSON (compatible with the earlier single-file version).
The service worker is generated by vite-plugin-pwa and auto-updates on each deploy.
